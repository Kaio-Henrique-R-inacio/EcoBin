# EcoBin — Site Institucional

Projeto acadêmico desenvolvido para a disciplina de **Inovação Tecnológica e Empreendedorismo**, do Curso Técnico em Desenvolvimento de Sistemas — 2º Ano.

## Arquivos

- `index.html` — estrutura e conteúdo
- `style.css` — layout, responsividade e visual
- `script.js` — menu mobile e validação do formulário
- `assets/logo.svg` — logotipo
- `assets/hero-bin.svg` — ilustração principal
- `assets/solution-ecobin.svg` — diagrama da solução

## Como abrir

Extraia o ZIP e abra `index.html` no navegador.

## Observação

O formulário é apenas demonstrativo: os dados não são enviados para um servidor.

- `assets/ecobin-logo.svg` — logo fornecida para o site.

## Imagens e logo
Esta versão usa a logo/ilustrações do projeto e também mantém cópias na pasta `assets/`.
As imagens principais estão incorporadas diretamente no `index.html`, então elas aparecem mesmo quando o arquivo é aberto localmente. Para publicar o projeto, envie a pasta inteira.
